# Project 02 — Product Listing Sample

## Purpose

A sample workflow showing how I organize information before and during product listing on an e-commerce marketplace.

## Listing Checklist

- [ ] Product name/title checked
- [ ] Product description completed
- [ ] Product images available
- [ ] Price checked
- [ ] Available stock checked
- [ ] Product variations checked
- [ ] Relevant promotion/voucher information checked
- [ ] Listing reviewed before publishing

## Sample Product Listing Structure

**Product Name:** Sample Product

**Category:** Sample Category

**Price:** PHP 499

**Stock:** 25 units

**Description:**
A clear and simple product description explaining the product's main features and useful information for customers.

**Variations:**
- Small
- Medium
- Large

**Listing Review:**
Before publishing, product information, price, stock, variations, and promotional details should be checked for accuracy.
